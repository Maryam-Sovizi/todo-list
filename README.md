# To-Do List

An Android To-Do List application developed as a bachelor's project.

## Description

This app allows users to organize their tasks into custom categories.  
Users can create their own categories (such as Work, University, School, etc.) and add tasks under each category.

For every task, users can set a specific time, and the app will send an alarm notification at that time.  
The application also includes a chart that displays the number and percentage of completed tasks.

## Features

- Create custom task categories
- Add, edit, and manage tasks in each category
- Set alarms for tasks
- View progress with a completion chart
- Simple and user-friendly interface

## How to Run

1. Open the project in Android Studio
2. Sync Gradle
3. Run the app on an emulator or a real device
